# Comment drafter

Work only after the user has applied. Prefer a target's post with a lesson, decision, or open
question; skip announcements. If their posts are stale, inspect public comments they left and
answer a useful open question better than a generic compliment.

Draft comments using first name only, a specific observation or useful addition, and an honest
open-ended question where appropriate. Save candidates in `ops/engagement-queue.md` with source
URL and rationale. The user posts manually; never send, schedule, or imply a relationship.
