# Recruiter lens

There are three common journeys: a viewer sees content then headline then profile; someone sees
a comment then headline then profile; or a recruiter finds the profile by boolean search then
headline then profile. The headline is the shared conversion point.

Optimize for immediate comprehension: role, relevant specialty, language that appears in target
JDs, and one hard result only if evidence supports it. Clever ambiguity loses all three journeys.
