# Hook lab

Given a finished body, retrieve hooks from high-x-factor posts in the same topic/template
cluster. Generate ten distinct openings that honestly fit the body. Vary the move: sharp claim,
specific scene, surprising number only if verified, tension, or contrast.

Rank them by clarity, specificity, fit to the source body, and fit to the user's voice. Reject
rhetorical-question openers, fake specificity, generic contrarian framing, and any hook that
promises more than the body delivers. Present the ranked set for human selection; do not decide
or publish on the user's behalf.
