# Post templatizer

Start with a retrieved high-x-factor post from local intel. Preserve attribution, URL, x-factor,
and the observed audience/context. Separate static structure from variable slots.

## Output format

Save/update `intel/reports/template-library.md` with:

- source URL, author, x-factor, media type, and template id;
- skeleton: hook → bridge → meat → mic drop → CTA;
- variable slots and what evidence they require;
- any distinctive visual concept and whether it needs credit;
- connective phrases that describe the *function*, not phrases to copy.

Never reproduce sentences or a distinctive argument sequence. The target is a reusable format,
not a derivative post.
