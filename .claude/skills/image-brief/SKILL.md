# Image brief

Return a concise production prompt, not an image file. Reference a proven image family when
available, explain the visual metaphor (left/right or before/after), and describe the feeling
to evoke rather than merely restating the facts. End with the post's mic drop the visual should
reinforce.

Also state aspect ratio, hierarchy, accessibility/alt-text suggestion, and any attribution
needed for a distinctive borrowed visual concept. Do not use a creator's artwork or text
verbatim.
