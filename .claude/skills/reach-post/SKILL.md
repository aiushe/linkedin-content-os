# Reach post

Use a broad, useful topic connected to a real pillar and format that has market evidence. A
how-to framing is allowed, but support it with a specific story, observed pattern, or clearly
labeled opinion. Do not pretend broad advice is a measured result.

Use the same workflow and queue frontmatter as `authority-post`: retrieval, truth check, five
hooks, `voice-check`, then `drafts/queue/`. Never publish automatically.
