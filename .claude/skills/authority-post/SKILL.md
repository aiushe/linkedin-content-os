# Authority post

1. Choose a pillar from `corpus/identity/pillars.md`.
2. Retrieve a proven format (`find_viral_posts`) and 3–5 relevant stories (`search_stories`).
3. Load the truth table and use only verified claims.
4. Draft: 2–3-line hook → bridge/story → deep educational meat → two-line contrast/mic drop →
   optional genuine question.
5. Generate five hook variants, then send the best draft through `voice-check` before writing.

Write in first person: what happened, how I made a decision, what I learned. Do not turn one
experience into a universal "how to" checklist. If a story lacks verification, remove numbers
and state the experience qualitatively. Save only a draft to `drafts/queue/` with frontmatter:
`pillar`, `story_ids`, `template_id`, `claims_checked`, `voice_check`, and `status: review`.
